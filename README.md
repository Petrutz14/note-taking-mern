# Note-Taking MERN App

A full-stack **MERN** (MongoDB, Express, React, Node.js) web application for creating, reading, updating, and deleting personal notes. Designed to be simple, user-friendly, and scalable.

---

## 📦 Features
 
- Create, edit & delete notes  
- View all your notes in a card layout  
- Real-time syncing between frontend and backend  
- Responsive design for desktop and mobile  

---

## 🧰 Tech Stack

- **Frontend:** React  
- **Backend:** Node.js + Express  
- **Database:** MongoDB  
- **API:** RESTful endpoints  
- **Styling:** Tailwind, DaisyUI
